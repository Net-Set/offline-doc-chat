# Stage 2 — Document 17: Production Readiness Checklist

| Field | Value |
|---|---|
| Document ID | DIP-PRC-01 |
| Version | 0.1 (template — **all items are unchecked**; nothing in this reference architecture has been verified in a running system) |
| Used at | Gate **G5** (production go-live, end of M14); a reduced subset is used at **G2** (pilot) and **G3** (AI enablement); the full list is re-run before each tier step (**G4**, **G6**) |
| Note | Independent reference architecture. Each item states the **evidence** that closes it. An item is complete only with linked evidence (report, dashboard, test run, signed approval). "Risk accepted" requires a named approver, rationale and expiry date. |

## How to use
1. Owner fills status: ☐ open · ◐ in progress · ☑ done with evidence · ⚠ risk accepted (approval linked).
2. **Go/no-go rule:** all items marked **[B]** (blocking) must be ☑ or ⚠ before launch; non-blocking items need a dated plan.
3. A DR or security claim is **valid only if its test passed within the last 12 months** (DR) / 6 months (pen-test, permission suite) — otherwise it is automatically reopened.
4. Evidence is stored with the release record; the checklist outcome is part of the audit trail.
